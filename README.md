# Local RAG 기반 PDF 문서 질의응답 AI 튜터

본 프로젝트는 외부 API(OpenAI 등)나 인터넷 연결 없이, 오직 로컬 GPU 자원만을 활용하여 구동되는 보안형 RAG(검색 증강 생성) 기반의 PDF 질의응답 웹 애플리케이션입니다. 데이터 유출 우려가 있는 민감한 문서를 안전하게 분석하고 대화할 수 있습니다.

## 주요 기능
- **동적 PDF 업로드:** 사용자가 웹 UI를 통해 실시간으로 새로운 PDF 문서를 등록하고 분석할 수 있습니다.
- **대화 문맥 기억:** 최근 대화의 맥락을 유지하여 이어지는 질문도 찰떡같이 이해합니다.
- **정확한 근거 출처 표기:** 답변의 근거가 된 PDF의 실제 페이지 번호를 하단에 명시합니다.
- **100% 로컬 프라이버시 보안:** Ollama 환경에서 `Llama3(8B)` 모델을 로컬로 구동하여 비용이 전혀 들지 않으며 완벽한 오프라인 보안을 자랑합니다.

## Tech Stack
- **Frontend:** Streamlit / **LLM Orchestration:** LangChain / **Vector DB:** FAISS / **Local LLM:** Ollama (Llama3)

## 사용 방법 (Usage Guide)
1. 문서 등록 (사이드바)
   - 웹 화면 왼쪽의 사이드바에서 `교재 PDF 파일`을 마우스로 드래그하여 업로드합니다.
   - "AI 조교가 문서 분석을 끝냈습니다."라는 문구가 뜨면 대화 준비가 완료됩니다.

2. 질의응답 및 대화 (채팅창)
   - 하단의 채팅창에 업로드한 문서 내용에 대해 궁금한 점을 질문합니다.
   - 예시: *"인공지능의 정의가 뭐야?"*

3. 연속 대화 및 문맥 기억 테스트
   - AI 조교가 답변을 완료하면, 주어를 생략하고 이어서 질문해 보세요.
   - 예시: *"방금 말한 그것의 장점은 뭐가 있어?"* (AI가 '그것'을 '인공지능'으로 인식하여 문맥을 이어갑니다.)

4. 출처 확인 및 대화 초기화
   - AI 답변 하단의 `근거 자료`를 통해 실제 PDF의 몇 페이지를 참고했는지 확인합니다.
   - 새로운 문서를 분석하거나 대화를 새로 시작하고 싶다면 왼쪽 사이드바의 `대화 기록 초기화` 버튼을 누릅니다.

## 설치 및 시작 가이드 (Getting Started)
프로젝트를 로컬 환경에서 구동하기 위해 아래 단계를 터미널에 순서대로 입력합니다.

### 1. Ollama 엔진 및 LLM 모델 설치
본 프로젝트는 로컬 LLM 구동을 위해 **Ollama**가 필수적으로 실행되어야 합니다.
1. [Ollama 공식 웹사이트(https://ollama.com)](https://ollama.com)에 접속하여 본인의 OS에 맞는 설치 파일을 다운로드하고 실행합니다.
2. Ollama 프로그램이 백그라운드에서 실행 중인 상태에서, 터미널을 열고 아래 명령어를 입력하여 `Llama3` 모델을 다운로드합니다.
```bash
ollama pull llama3
```
### 2. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```
### 3. 웹 애플리케이션 실행
```bash
py -m streamlit run app.py
```
